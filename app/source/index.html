The module engine/xtb_wasm.wasm is the axtb library, version 0.1.2, and a small wrapper with a flat C interface. Everything needed to build it again is here, including with a modified version of axtb.

The wrapper is under the MIT license. You may change it and rebuild the module, also with a modified version of axtb.

Building

  1. Install Rust 1.89 or later and the wasm32-wasip1 target: rustup target add wasm32-wasip1.
  2. Get axtb: git clone https://github.com/atomsforhumanity/axtb, commit 675f523e4eb3baf49ad0d90d5ccddf4de6b8677f (or your own modified version).
  3. In xtb-wasm/Cargo.toml, set the path to the crates/axtb directory of that clone in the line axtb = { path = "…" }.
  4. In the xtb-wasm directory, run cargo build --release --lib --target wasm32-wasip1.
  5. Replace engine/xtb_wasm.wasm on the site with the file target/wasm32-wasip1/release/xtb_wasm.wasm.

The module calls six WASI functions; their implementation and a description of its interface are in xtb-binding.js.
