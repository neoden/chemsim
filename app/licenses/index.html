The file engine/xtb_wasm.wasm contains the axtb library, version 0.1.2 (the GFN2-xTB method), which is distributed under the GNU Lesser General Public License, version 3 or later; it supplements the GNU General Public License, version 3. Where the parameters and algorithms of axtb come from is stated in its NOTICE; how the licenses apply to the parts of axtb is in its LICENSE.

The library is used unmodified. Its source code: github.com/atomsforhumanity/axtb, commit 675f523e4eb3 (tag v0.1.2). The source code of the wrapper it is built into the module with, and instructions for rebuilding with a modified version of the library, are next to the site.
